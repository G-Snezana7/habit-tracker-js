# Интерактивный трекер привычек (Habit Tracker JS)

Мини-приложение для отслеживания ежедневного прогресса выполнения привычек, полностью спроектированное и разработанное на чистом JavaScript (Vanilla JS) с геймификацией логики и сохранением сессии.
## 🚀 Демонстрация проекта
* **Живой сайт (GitHub Pages):** https://g-snezana7.github.io/habit-tracker-js/

## 🛠️ Стек технологий и архитектура

- **Логика и состояние:** Vanilla JavaScript (ES6+) — реализация реактивного обновления интерфейса через перерисовку состояния данных приложения. Использован современный иммутабельный подход (`.filter()`, оператор `spread`).
- **Хранение данных:** LocalStorage API — динамическое кэширование списка задач и их счетчиков. Данные сохраняются при закрытии вкладки или обновлении страницы.
- **Верстка и БЭМ:** Семантический HTML5 и CSS3. Код структурирован по методологии БЭМ, что гарантирует независимость и чистоту стилей.

## 💡 Уникальные фичи и продуктовая логика

1. **Защита от накрутки (Бизнес-логика дат):** Реализован алгоритм контроля времени на базе `Date API`. Пользователь может отметить привычку выполненной только один раз в сутки. При клике кнопка блокируется, фиксируя дату, и восстанавливает активность только на следующий день.
2. **Живая валидация интерфейса:** Автоматическое отслеживание ввода в текстовое поле на лету (`input` event). Кнопка «Добавить» физически блокируется и становится неактивной, если поле ввода пустое или содержит исключительно пробелы (защита от отправки пустых данных).
3. **Удобный UX:** Добавлена возможность отправки формы и создания новой привычки как по клику на кнопку, так и по нажатию клавиши `Enter` на клавиатуре.
4. **Доступность (a11y):** Динамически создаваемые элементы управления снабжены атрибутами `aria-label`, благодаря чему интерактивные счетчики и скрытые кнопки удаления корректно озвучиваются экранными дикторами (скринридерами) для слабовидящих людей.
